Which keyboard layout to use?

For English use Qwerty, Dvorak or Colemak, for German language use Qwertz layout. AZERTY for French. Russian and Spanish layouts are available.

WPM

WPM (Words per minute) is used to measure your typing speed. A word is considered of 5 letters.

How to type faster?

You should learn touch typing to type faster. You can practice our lessons for the same.

How typing test text is generated?

It is generated randomly from a list of common words. You can include punctuation and numbers in the text by enabling those options.
